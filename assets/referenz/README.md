# Jeans-Referenzmaterial

Das Paket kommt in drei ZIP-Dateien (je unter 20 MB): Teil 1 = Texte + Posen-Fotos + 3 Nahaufnahmen, Teil 2 = restliche 5 Nahaufnahmen, Teil 3 = Videoclips. Alle drei entpacken sich in denselben Ordner `jeans-referenz/`.

Testhose 1: hellblaue Baggy/Wide-Leg-Jeans.

Referenzmaterial für die virtuelle Anprobe. Alle Aufnahmen zeigen dieselbe hellblaue,
weit geschnittene Jeans, getragen von Jakob (1,79 m), in Socken, auf Holzboden.

Die Fotos wurden von HEIC nach JPG umgewandelt (volle Auflösung 3024×4032, richtig gedreht, JPG-Qualität 85).
Die Videoclips sind Ausschnitte aus zwei iPhone-Videos (IMG_7315, IMG_7316), hochkant
720×1280, 30 fps, H.264, ohne Ton (verkleinert für den Versand; die Original-Videos in 1080p hast du selbst). Kamera steht tief am Boden, leicht nach oben gerichtet.
